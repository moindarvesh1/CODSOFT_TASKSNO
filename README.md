# CodSoft Cyber Security Internship

## About
This repository contains projects completed as part of the CodSoft Cyber Security Internship. The projects focus on cybersecurity awareness, network packet analysis, and secure coding practices.

## Projects

### Task 1: Network Packet Analyzer
A Python-based project to capture and analyze network packets, including source and destination IP addresses and protocol information.

### Task 2: Phishing Awareness Program
An educational presentation explaining phishing attacks, warning signs, prevention techniques, and online safety practices.

### Task 3: Secure Code Assessment
A security assessment project focused on identifying potential code vulnerabilities and recommending secure coding practices.

## Technologies
- Python
- Git and GitHub
- Cybersecurity fundamentals

## Objective
To gain practical experience in cybersecurity, improve technical skills, and understand common security risks and prevention methods.
